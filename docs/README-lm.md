# 輕量創界 (Light Minecraft, LM) 系統手冊

輕量創界是一個整合了 2D 畫布與 LPC 邏輯的開放式沙盒世界。玩家可以在此移動、挖掘、建造，並透過 Emoji 文字地圖快速生成複雜的地形與生物配置。

---

## 🚀 進入與離開

### 進入創界
在遊戲中輸入以下指令即可傳送至創界核心：
- `lm`
- `minecraft`

### 離開創界
在創界中輸入以下指令可返回新手村：
- `mc leave`
- 或者使用畫布上方工具列的 **[Exit World]** 按鈕。

---

## 🎮 操作指南

### 移動
- **快速鍵**：進入創界後，可直接使用鍵盤的 `W` `A` `S` `D` 或方向鍵進行上下左右移動。
- **指令**：`mc move <n|s|e|w>`。

### 挖掘與放置 (互動模式)
1. **挖掘 (Dig)**：
   - 在畫布工具列選擇 **[Dig (Click)]**。
   - 用滑鼠點擊畫布上的方塊即可挖掘，方塊會自動掉落進你的背包。
   - 指令：`mc dig <x> <y>`。
2. **放置 (Place)**：
   - 在畫布工具列選擇 **[Place (Click)]**。
   - 在下拉選單選擇要放置的方塊類型（需確保背包內有該方塊）。
   - 用滑鼠點擊空白處即可放置。
   - 指令：`mc place <x> <y> <類型>`。

### 介面功能
- **滾輪縮放**：在畫布上使用滑鼠滾輪可放大或縮小地圖。
- **同步地圖**：若畫面未更新，輸入 `mc map` 可強制重新整理。

## 🏗️ 建立地圖 (Emoji Import)

這是 LM 系統最強大的功能，允許你使用純文字 Emoji 網格來「繪製」世界。

### 方法一：網頁快速導入 (推薦)
1. 點擊畫布上方的 **[📥 Import Map]** 按鈕。
2. 在彈出的對話框中貼上 Emoji 地圖內容。
3. **建造邏輯**：系統會以你「目前所在座標」作為左下角，向右上方覆蓋生成地形。

### 方法二：讀取伺服器檔案
如果你是巫師 (Wizard) 或神 (God)，可以使用指令直接讀取伺服器內的檔案：
- 指令：`mc build <檔案路徑>`
- 範例：`mc build /data/lm/maps/README-lm-3.md`

## 📝 範例地圖格式

你可以直接複製以下內容並透過 **[Import Map]** 按鈕貼上：

```text
🟦🟦🟦🟦🟦🟦
🟦☁️🟦🟦☁️🟦
🟩🟩🟩🟩🟩🟩
🟩🟩🟫🟫🟩🟩
🟩🟩🟫🚶🟩🟩
🟩🟩🟫🟫🟩🟩
🟩🟩🟩🟩🟩🟩
```

*注意：每行長度不一定要相等，系統會自動處理。空格或不支持的符號會被視為「空氣」並清除該位置的現有方塊。*

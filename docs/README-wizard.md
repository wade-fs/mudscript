  1. 新增的管理指令 (位於 /cmds/admin/)
  現在巫師可以在遊戲內使用以下指令進行開發：

  | 指令   | 用法          | 說明                                                            |
  |--------|---------------|-----------------------------------------------------------------|
  | ls / dir| ls [路徑]     | 列出檔案與目錄，並顯示檔案大小（目錄顯示為綠色）。              |
  | cat    | cat <檔案>    | 直接在終端機查看檔案內容。                                      |
  | rm     | rm <檔案>     | 刪除指定的檔案。                                                |
  | mkdir  | mkdir <路徑>  | 建立新目錄。                                                    |
  | rmdir  | rmdir <路徑>  | 移除空目錄。                                                    |
  | grep   | grep <關鍵字> <檔案>| 在檔案中搜尋包含關鍵字的行，並顯示行號。                  |
  | find   | find <關鍵字> [目錄]| 在指定目錄下遞迴搜尋檔名符合的檔案。                      |
  | sed    | sed <檔案> <舊字串> <新字串> | 直接替換檔案中的特定文字內容。                   |
  | edit   | edit <檔案>   | 線上文字編輯器。進入後可逐行輸入，支援 .l (列出)、.d (刪除)、.i (插入)、.x (儲存退出) 等子指令。|
  | upload | upload <檔案> | 批次上傳。適合從本機複製整段程式碼貼上，輸入單獨一行的 . 即可完成上傳。|

  2. 線上編輯器 (edit) 子指令說明
  進入 edit 模式後，每一行輸入都會被視為檔案內容。若要執行編輯操作，請使用 . 開頭的指令：
   * .l：列出目前緩衝區的所有內容（含行號）。
   * .d <n>：刪除第 n 行。
   * .i <n> <文字>：在第 n 行之前插入一行文字。
   * .s：儲存檔案但不退出。
   * .x 或 .：儲存並退出編輯模式。
   * .q：放棄修改並退出。
   * .h：顯示幫助清單。

  3. 底層強化
  為了支援編輯器與上傳模式的暫存狀態，我已在 /std/object.c 中新增了基礎設施：
   * set_temp(key, val)：設定物件的暫時性變數（不存檔）。
   * query_temp(key)：查詢暫時性變數。
   * delete_temp(key)：刪除暫時性變數。

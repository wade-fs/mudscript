- 玩家:
	- 可以組隊, 自動 follow
- npc: 
	- 設定和平與好鬥分子
	- 會記住最後一個戰鬥的玩家，下次見面血量夠高就自動發起攻擊
- room:
	- 每個主要房間應該都有老闆，可以走動，走到房外可以被砍，要定時重生
	- 應該要有特殊房間，譬如有洞可以 dig/search ，dig/search 之後才出現之類的
- item
	- 寶箱，可以打開，可以get 裡面的物品
	- 可拿、不可拿、不可掉落
	- 裝備、鑑定
	- 升級、鑲嵌
	- 清單顯示
	- 破損、修補、報廢
	- 鍛造
	- 區域地圖
	- 虛擬地圖
- quests
	- 收集徽章
	- 收集物資
	- 戰鬥
	- 升級
	- 遊歷
	- 對答

# 常用指令參考表
指令                        | 說明
----------------------------|---------------------------------
gemini analyze .            | 掃描當前整個專案架構並生成摘要。
gemini fix "go build error" | 讀取編譯錯誤訊息並自動嘗試修復代碼。
gemini test --auto          | 自動為目前尚未覆蓋測試的函式撰寫測試代碼。
gemini commit               | 根據目前的更改內容自動生成 git commit 訊息並提交。

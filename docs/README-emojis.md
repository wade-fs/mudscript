# 幾何 Tile（超重要）

這些比 emoji 更適合真正蓋地圖。

## 方塊

```text
█ ▓ ▒ ░
■ □ ▪ ▫
⬛ ⬜ ◼️ ◻️
```

---

## 半格

```text
▀ ▄
▌ ▐
```

可做：

- 光影
- 地形高度
- 水面
- voxel 感

---

## 線條 / 牆壁

```text
│ ┃ ─ ━
┌ ┐ └ ┘
├ ┤ ┬ ┴ ┼
╔ ╗ ╚ ╝
═ ║
```

# 真正進階玩家會用的 Unicode 類別

如果你想做完整「文字遊戲引擎」：

| Unicode 區塊 | 用途 |
|---|---|
| Box Drawing | UI / 牆壁 |
| Block Elements | voxel / tile |
| Geometric Shapes | 地圖 |
| Braille Patterns | shading |
| Misc Symbols | RPG |
| Emoji | 主視覺 |
| ANSI Colors | 真正畫面感 |

---

# 額外推薦：Nerd Fonts

很多 terminal 玩家會再加：

- Powerline Symbols
- Nerd Font Icons
- Devicons

能得到超多：

- 電路感
- sci-fi UI
- cyberpunk HUD
- RPG inventory

效果會比純 emoji 更強。

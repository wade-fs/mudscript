## 🚚 區域網絡物資循環流向

1. **原材進城**：
   - 重石縣（鐵石）與盤木縣（木料）大料匯入都城南關外的「大料初堆棧」。
   - 烈礬縣（硫礬）與青河縣（藥材）經北門、西水門入城，送交百工總會分業工坊。
2. **精製品輸出**：
   - 百工總會精製之兵刃、鎧甲與火器，調派至鎮風縣邊關及東部軍鎮。
   - 宣道司符籙與通寶錢莊銀票流通於全府六縣。
3. **修士歷練路線**：
   - 玩家於**黑石鋪**完成 Tier 0 基礎試煉 $\to$ 沿**南嶺官道**進駐**金石府城** $\to$ 於宣道司/鎮武軍鎮/百工總會選定門派道統 $\to$ 奉令奔赴六縣邊陲應對大荒煞潮危機。

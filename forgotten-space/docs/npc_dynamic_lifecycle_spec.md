# 《遺忘的世界》NPC 動態生態、時空流轉與任務相位系統規劃
# (NPC Dynamic Lifecycle, Schedule & Quest-Phasing Specification)

> **設計核心方針**：  
> 打破傳統 MUD「活木樁型 NPC」的陳舊格局，建立具備**「日常時辰作息（Schedule）」**、**「事件動態遷徙/瞬移（Event Phasing）」**與**「跨地圖連鎖任務分發（Multi-Phase Progression）」**的活態 NPC 生態系統。  
> 讓同一個人物在不同時節、不同地點、不同任務時期展現出立體的生命軌跡與差異化行為。

---

## 一、設計動機與核心願景

### 1. 現狀痛點
- 傳統 MUD 中，NPC 往往 24 小時永久固定於單一房間，即便村落發生滅頂之災、山崩地裂，NPC 依然面帶微笑重複著最初的新手導引台詞。
- 任務往往局限於「原地接任務 → 出去打怪/採藥 → 原地交任務」，NPC 缺乏個人命運與行動軌跡，世界感顯得扁平僵硬。

### 2. 本系統願景
- **生態呼吸感**：NPC 遵循天時作息，晨興夜寐，日出而作，日落而息；
- **事件命運感**：當重大事件或主線推進時，NPC 會離開安全區，甚至遇險被困於險境深淵；
- **長線羈絆感**：同一個 NPC 隨玩家歷程跨越地圖遷徙，在村落是鄰里長輩，在險境是落難夥伴，在名山是引路故人。

## 二、NPC 三態生命週期模型 (The Three-State Model)

```
       ┌────────────────────────────────────────────────────────┐
       │                 1. 日常作息態 (Routine)                 │
       │  依據 nature_d 十二時辰與天氣，在聚落生活圈內規律位移    │
       └──────────────────────────┬─────────────────────────────┘
                                  │ 全域事件爆發 / 個人任務推進
                                  ▼
       ┌────────────────────────────────────────────────────────┐
       │               2. 事件/任務相位態 (Phased/Incident)       │
       │  NPC 瞬移/避難/受困於任務專屬危險地點，化身特殊任務人物  │
       │  （對話樹替換、行為動詞特化、提供緊迫救援/解鎖特殊機制）│
       └──────────────────────────┬─────────────────────────────┘
                                  │ 危機解除 / 任務完成結算
                                  ▼
       ┌────────────────────────────────────────────────────────┐
       │                3. 記憶回歸/進化態 (Evolution)           │
       │  回歸聚落生活圈，但具備事件記憶、好感度提升與後續任務鏈  │
       └────────────────────────────────────────────────────────┘
```

### 1. 日常作息態 (Diurnal Routine State)
- **觸發源**：`/secure/nature_d.c` 推進的遊戲時辰與氣候。
- **行為表現**：
  - **時辰作息表 (Schedule Matrix)**：
    * `卯時 (05:00-07:00 清晨破曉)`：NPC 準備上工、溪邊取水、磨刀、舒展筋骨；
    * `辰時至午時 (07:00-13:00 上午至正午)`：主要工作地點（街市開檔、礦道口採礦、田間勞作）；
    * `申時至酉時 (15:00-19:00 傍晚黃昏)`：收工歸市、老客棧或茶棚聚飲、閒聊市井傳聞；
    * `戌時至寅時 (19:00-05:00 深夜黑夜)`：返家閉門歇息、深巷暗市出沒，或防獸巡邏。
  - **空間移動方式**：
    * 鄰近相鄰房間：呼叫 `do_wander` 或 `broadcast_event("say_leave")` 配合 `move_object` 進行自然走動。

### 2. 事件/任務相位態 (Quest / Incident Phase State)
- **觸發源**：全域世界事件（`WORLD_STATE_D`）或個人任務鏈推進（`QUEST_ENGINE_D`）。
- **核心機制：瞬移與型態置換 (Teleport & Mutate)**：
  - **平常是「普通日常 NPC」**：
    * 提供基礎問答、生活買賣、技能初級傳授。
  - **任務期切換為「特殊任務 NPC」**：
    * **位置瞬移**：NPC 從常駐房間消失（或留下一張留條/帶血工具），轉移至險境現場；
    * **形象與語氣突變**：傷重倒地、被困巨石之下、手持兵刃警戒等；
    * **話題與行為特化**：
      - 普通話題關閉，替換為緊急求救、關鍵情報或傳授解困法門；
      - 解鎖專屬指令（如：`rescue`、`bandage`、`feed_potion`、`escort`）；
    * **多玩家隔離考量**：
      - *全服公共事件*：如礦脈坍塌期間，全村人都知道魯大山被困地底；
      - *個人獨立任務鏈*：透過客戶端視角過濾或鏡像 NPC，確保不影響尚未觸發事件的新手。

### 3. 記憶回歸與演化態 (Evolution State)
- 任務達成後，NPC 獲救或危機解除：
  - **回歸表現**：NPC 返還聚落，但對話永久更新（如：「多虧小兄弟當日在地底崩塌時砸碎卡隼石救我一命，老夫這條命是你給的！」）；
  - **權限與資源解鎖**：開放底層秘密對話、高階礦石收購、進階功法傳授，甚至贈予家族信物。

## 三、經典落地案例演繹 (黑石鋪三巨頭)

### 案例 1：老礦工【魯大山】（採礦師傅 → 地底落難者 → 史前開脈先導）
1. **日常態（平時）**：
   - 位置：`/d/village/mine.c`（黑石斷崖・古礦道口）；
   - 角色：教導新手如何 `mine` 採礦打熬臂力，收購粗黑鐵礦，感嘆礦道年久失修。
2. **任務期（第 13-14 章地煞崩塌事件）**：
   - 礦道口只剩慌亂呼救的年輕學徒；
   - 魯大山本體出現在 `/d/village/mine_depths.c`（地下崩塌坑道深處）；
   - 狀態：帶領二十三名老礦工退守避風穹頂，以三長兩短敲擊鐵軌求生；
   - 任務：玩家必須調製辟煞藥酒、向枯水求定脈符、使用百煉破煞鋼鑿擊碎卡隼石方能救出。
3. **回歸演化態（第 15 章及以後）**：
   - 魯大山回到聚落老鐵匠鋪旁療傷歇息；
   - 解鎖新話題 `ask lao miner about 地煞` / `太古殘圖`，成為後續進軍幽冥地煞主線的關鍵引路人。

### 案例 2：張屠戶【張三】（溪灘磨刀漢 → 市井肉鋪掌櫃 → 獵場突襲者）
1. **清晨作息**：在 `/d/village/stream.c` 溪灘磨礪生鏽砍刀，大聲抱怨山洪與生計，無意間震碎古碑石垢；
2. **上午作息**：收拾砍刀走回 `/d/village/square.c`（青石街市肉攤），高聲叫賣新鮮山豬肉與獸骨；
3. **特殊任務期（第 3-5 章獸潮危機）**：
   - 因得知東林獵戶受困，張屠戶提著雪亮砍刀動身前往大荒外緣哨亭，化身兇悍的戰鬥型 NPC，與玩家並肩抵禦暴躁獸群；
   - 提供斬骨刀法進階心得。

### 案例 3：老獵戶【趙老獵】（巡林者 → 東林營地獵王 → 深入黑石禁區）
1. **第一階段（村落）**：在中央街市酒棚發布基礎捕獸任務（調校陷阱、辨識獸跡）；
2. **第二階段（前線哨亭）**：任務完成後，趙老獵整裝出村，駐紮在大荒外緣 `/d/village/hunting_path.c` 深入處的臨時獵棚；
3. **第三階段（禁區引路）**：引導玩家從初級打獵過渡到追蹤被地煞魔化的異獸首領，推動第一卷中期劇情。

## 四、未來系統架構實作藍圖 (Technical Roadmap)

### 1. 守護進程規劃：`PHASE_D` (相位與生態守護進程)
- **職責**：
  * 維護全域 NPC 作息時間表：`mapping npc_schedules`；
  * 提供 `check_npc_phase(string npc_id, object player)` 介面，依據玩家進度與世界狀態動態決定該 NPC 應出現於何處；
  * 監聽 `/secure/nature_d.c` 的時辰跳轉廣播（`event_shichen_change`），定時排程驅動 NPC 移位。

### 2. Room 基類與 NPC 虛擬生成整合
- 在 `/std/room.c` 的 `spawn_npc()` 中引入相位感知：
  ```c
  // 若該 NPC 目前處於特殊任務相位或在外作息，原房間不予重複生成
  if (PHASE_D->is_npc_phased_away(npc_file, this_object())) {
      return 0;
  }
  ```
- 在任務房間中動態注入任務態 NPC（帶有專屬 AI 與事件對話旗標）。

### 3. 對話系統 (`ask_topics`) 的條件過濾
- 支援以閉包或條件判斷動態呈現話題：
  ```c
  // 偽代碼示例
  set_topic("救命", (: do_emergency_help :), ([ "phase": "mine_collapse" ]));
  set_topic("採礦", (: do_mining_teach :), ([ "phase": "normal" ]));
  ```

## 五、結論與後續排期

本規格定義了一套極具沉浸感的「NPC 呼吸與命運流轉體系」。  
當前階段已將核心思想完整落盤歸檔，後續可依據主線劇情推進節奏，分模組逐步落實：
1. **Phase 1**：在黑石鋪先挑選 1-2 名核心人物（如魯大山、張屠戶）進行作息時辰與任務坑道位移試點；
2. **Phase 2**：形式化 `PHASE_D`，與現有 `QUEST_ENGINE_D` 無縫對接；
3. **Phase 3**：全面覆蓋各章節重要配角之跨圖流轉。

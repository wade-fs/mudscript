# Tier 3 時間軸與兩界校時表（第四卷規劃）

> **核心設定** (`ch0126.md` & `world_setting.md` §4.1)：洞天頭頂是一片詭異暗鐵青色、彷彿永遠停留於黎明前壓抑時刻的靜止天穹，沒有熟悉日光與二十八宿自然更迭；**但「無日月更迭」不等於「無時間流逝與資源衰變」**（§3.12）。體內飢餓、晶柱耗竭、器械磨損與「三百年天羅大校準倒數」依然精準走時。

## 2. 時間設計規則

1. 洞天無日出日落，書寫時須以**「主機低頻轟鳴換班週期」、「鹽晶儲柱更換記號」、「律令排異傷員服藥間隔」**表現時間流動，切忌寫成失去時間概念的真空。
2. 嚴守「三十年之約」時間約束：第四卷結束僅過約三年（並非一年神速推關或百年無感閉關），使凡間莫三、宋知微、雷烈與燕隼尋親故事保有一致的壽命與衰老跨度。
3. 雙向信標每次開放嚴格限制**三息時間視窗暨半斤載重上限**，絕不在第四卷結束前演變成兩界任意通車的商業高速路。

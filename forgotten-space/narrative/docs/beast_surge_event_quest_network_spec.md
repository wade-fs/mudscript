## 一、系統核心理念 (Core Philosophy)

傳統 RPG 任務多為「孤立線狀、交任務拿獎勵、世界靜態等待玩家」。本系統將「黑石鋪大荒煞潮」重構為一個**事件型任務系統（World Event Quest Network）**：

1. **共同事件 (Common Event)**：獸潮持續逼近黑石鋪，所有任務都在處理同一場全域生存危機。
2. **多條並行任務線 (Parallel Quest Lines)**：勘測、工程、醫療、物資、居民疏散、情報、政治交涉等並行開放。
3. **共享世界狀態 (Shared World State)**：一項任務的成果會動態改變其他任務的難度、可用選項與最終結果。
4. **沒有唯一解法 (No Single Solution)**：玩家可以成功改道，也可能只能疏散居民、保住部分物資，甚至在失敗後協助重建。
5. **時間會繼續走 (Independent Clock & Simulation)**：玩家不做某些任務，NPC 仍然會自主行動，獸群仍然會移動，局勢也可能惡化或被其他 NPC 改變。

## 三、具體任務規格設計 (Quest Specifications)

### A 線：生態勘測——獸群為什麼逃跑？

> **設計重點**：玩家不必完成全部三個任務才能知道獸潮將至。不同線索可以互相替代，但資訊的精確程度會影響後續決策。

#### A01｜暴斃黃羊
* **類型**：探索 / 可獨立完成
* **委託與情境**：顧玄需要判斷黃羊死亡原因。玩家可以尋找屍體、採集樣本、詢問獵人，或把樣本交給不同人士檢查。
* **分級結果**：
  * **成功**：取得呼吸道受損、氣管焦黑硫粉之病理毒理證據，確立急性窒息死因。
  * **部分成功**：確認不是一般野獸撕咬外傷，但無法判斷確切毒源。
  * **失敗**：樣本遭破壞或污染，仍可從其他野獸或林緣地形取得替代線索。

#### A02｜逆行獸跡
* **類型**：野外探索 / 時間敏感
* **委託與情境**：追蹤不同獸種的足跡、糞便、飲水點和逃逸方向。不是殺死野獸，而是判斷牠們正在逃離什麼。
* **分級結果**：
  * **成功**：找出北方地煞毒源及獸群「由北向西南發散」的主力路線（食草獸先行、肉食獸尾隨）。
  * **部分成功**：知道獸群正由北往南逃逸，但不確定主力衝擊路徑。
  * **失敗**：追蹤者受傷或錯判方向，導致工程部署時間延誤。

#### A03｜落龍三岔口
* **類型**：地形調查 / 支援工程線
* **委託與情境**：測量坡度、谷口寬度、風向、可通行性與崩塌風險。玩家不一定需要懂全部原理，也可以採集測量工具、護送勘測者或標記路線。
* **分級結果**：
  * **成功**：工程線可選定最安全的階梯導流位置與風眼。
  * **部分成功**：能改道，但需要消耗更多工時與備用材料。
  * **失敗**：錯誤導流可能讓部分獸群在崩塌時轉向聚落。

### B 線：地形工程——讓獸群自然偏轉

> **設計重點**：工程成果不是「二元開關（獸潮是否被控制）」，而是動態改變獸群分流的機率、主力路線及抵達時間，與 A 線勘測成果強依賴。

#### B01｜老礦工的石眼
* **情境**：尋找古採石場的石眼、鉸盤、絞盤和可用工具。可以請老礦工協助，也可以用其他材料製作替代裝置。
* **分級結果**：
  * **成功**：取得可重複操作的古青銅拉索與配重機構。
  * **替代方案**：使用大量人力配合粗糙簡易木槓桿。
  * **失敗代價**：工時大幅增加，部分工人可能因設備斷裂受傷。

#### B02｜萬斤落石
* **情境**：組織工人架設階梯式導向石陣。玩家要選擇安全性、施工速度與導流效果，而不是單純交付十塊石頭。
* **分級結果**：
  * **成功**：主要路線被安全引導向落龍深澗，且不會自毀道路。
  * **部分成功**：主力偏轉，但側翼仍有一成至兩成殘獸漏入聚落。
  * **失敗**：石陣提前崩落堵死主幹道，引發野獸踩踏並將獸群逼向黑石鋪。

#### B03｜逆風草煙
* **情境**：收集刺激性草料（辣蓼、老狼糞、硫磺渣）、安排低溫悶燒煙堆位置、觀測風向變化。玩家若只交付材料而忽略風向，任務依然可能失敗。
* **分級結果**：
  * **成功**：配合清晨谷風形成刺鼻屏障，顯著降低獸群進入聚落方向的機率。
  * **部分成功**：煙霧擴散效果有限，但爭取到局部疏散時間。
  * **失敗**：正午山風倒灌反噬村落，迫使居民緊急撤離下風區域。

### C、D、E 線：讓聚落有能力撐過危機

> **核心原則**：救援不是純粹的善行支線，而是會**消耗時間、人力與物資的真實選擇**。投入人手搜救失蹤者，可能石陣就少兩名工人；但放棄搜救，居民也可能拒絕配合後續工程。兩種選擇都產生合理代價。

| 任務代號與名稱 | 主要面臨問題 | 可行解法 | 對共享世界狀態的影響 |
| :--- | :--- | :--- | :--- |
| **C01 糧倉盤點** | 糧食不足、商人惜售、價格飆漲 | 公平配給、市場合理交易、徵購或交換勞務 | 提升聚落糧食存量、穩定居民信任度 |
| **C02 百工借料** | 缺焦煤、缺硬木、缺乏加固工具 | 向商隊借用、拆解廢舊木料、尋求替代工藝 | 加快工程施工速度，但其他手工業暫時停擺 |
| **D01 最後一包止痛散** | 藥品存量枯竭、重傷者呻吟 | 殘酷分級救治、採集草藥代用品、轉移重傷者 | 決定傷患存活率、影響家屬勞動意願 |
| **D02 暗渠避難** | 堅固避難所容量有限 | 分區安置、疏通太古排沙暗渠、設置引路標記 | 擴大避難容納量、大幅降低踩踏與走失風險 |
| **E01 誰來守街口** | 居民恐懼傷亡、不願冒險上柵 | 組織輪值防禦、承諾撫卹補償、鄰里互助結伴 | 增加臨時民兵人數、維持街市治安防搶 |
| **E02 失蹤的孩子** | 家屬悲痛、與工程救援隊衝突 | 抽調人手搜尋、交換巷尾情報、優先定向搜救 | 改變特定家庭關係、扣減工程人力、解鎖後續援助 |

---

### F 線：情報查證——坩堝到底證明了什麼？

> **設計重點**：這條線可以早於獸潮完成，也可以延後到獸潮結束後才有結果。它不決定獸潮能否生還，但直接決定後續官軍扣關時，黑石鋪是「被定性為叛亂遭屠滅」，還是「手握對等調查籌碼」。

#### F01｜破碎貨箱
* **情境**：調查私逃失敗的商隊遺留貨箱、坩堝、貨物標記和目擊者證詞。
* **推論邊界**：坩堝能證明貨物來源與特定工藝，但不能單獨證明誰是炸礦元兇。

#### F02｜暗賬缺頁
* **情境**：尋找金石商隊賬簿、運貨出入紀錄與被撕毀的缺失頁面。
* **可行途徑**：賄賂帳房、說服知情老護衛、夜潛倉庫搜查，或以其他庇護條件交換證據。

#### F03｜證詞互證
* **情境**：將老礦工魯大山、商隊護衛、客棧掌櫃和工匠的說法互相比對。
* **核心機制**：證詞可能出於恐懼、利益或記憶偏差，玩家必須辨別哪些部分能與物證獨立核實。

---

### G、H 線：殘獸防衛與官軍交涉

> **設計重點**：官軍絕非只有「被說服」與「被擊敗」兩種二元結果。指揮官可以相信部分證據，卻仍然封鎖聚落；也可以懷疑胡百戶，但因軍令不敢立即撤兵。

| 任務代號與名稱 | 玩家要處理的核心問題 | 可能產生的世界結果 |
| :--- | :--- | :--- |
| **G01 木柵缺口** | 10% 離群狂暴殘獸與孤狼突破外圍 | 頑強守住狹窄巷道、局部院落失守、傷亡人數增加 |
| **G02 撤離老弱** | 撤離安全路線與運載人手發生衝突 | 更多老弱婦孺生還，但部分笨重商貨被迫拋棄 |
| **G03 被困的採礦隊** | 選擇冒險救人，或保全最後一道防禦工事 | 成功救出熟練礦工、失去外圍工事，或兩者皆有損耗 |
| **H01 胡百戶的軍令** | 查明軍隊真實目的、軍令來源與補給短板 | 迫使胡百戶延緩進攻、暴露情報矛盾，或激化局部敵意 |
| **H02 多點投書** | 將證據同時送到前鋒百戶、督糧官、隨軍監軍手中 | 瓦解單一壓制可能：有人立案調查、有人截留、有人藉機自保 |
| **H03 陣前核證** | 在三軍陣前公開展示雷管實物與殘廢礦工人證 | 爭取到暫停攻擊、就地扣押胡百戶、轉入「駐關待查」狀態 |

## 四、核心機制：共享世界狀態矩陣 (Shared World State)

為了避免任務網退化成孤立支線，系統以 **6 個核心全域變數** 作為即時連動樞紐：

| 變數名稱 | 代表意義 | 離散等級 / 有限狀態 | 對其他任務與世界的實質影響 |
| :--- | :--- | :--- | :--- |
| `herd_pressure` | 獸群對黑石鋪的即時威脅程度 | 遠距預警 / 兵臨峽口 / 狂潮過境 / 殘獸潰散 | 決定各任務剩餘時間窗、殘獸規模、疏散緊迫性 |
| `route_confidence` | 對獸群遷徙路線判斷的可信度 | 毫無頭緒 / 初步推測 / 多項實證支持 | 決定 B 線工程的成功率、誤導與分流失敗機率 |
| `diversion_effect` | 導流改道措施的實際物理效果 | 無效果 / 局部偏折 / 顯著分流 | 決定主力是否直撞聚落、G01 防衛強度、後續官道破壞程度 |
| `settlement_capacity` | 聚落的人力、物資儲備與救援承載力 | 崩潰邊緣 / 緊繃匱乏 / 勉強自足 / 充沛穩定 | 決定 B 線工程速度、D 線傷患存活率、民兵招募人數 |
| `evidence_strength` | 官軍與上層能獨立核實的證據強度 | 市井傳聞 / 單一物證 / 交叉互證 / 鐵證如山 | 決定 H 線能否迫使軍隊停戰、是全村遭戮還是立案徹查 |
| `civilian_trust` | 居民對組織者、商隊及彼此的信任度 | 恐慌猜忌 / 利益觀望 / 有限協作 / 患難互助 | 決定 NPC 是否私自逃亡、哄搶物資、是否願意留守施工 |

### 因果連動示例

```
  【A02 逆行獸跡】完成
          │
          ▼ 提高 route_confidence
  【B02 萬斤落石】施工成功率大幅提升
          │
          ▼ 提高 diversion_effect
  ┌───────┴────────────────────────┐
  ▼ (改道顯著生效)                  ▼ (改道失效或僅局部)
【G01 木柵防衛】壓力降低，         【G02 緊急撤離】必須立刻啟動，
守衛力量可集中於少數隘口          否則 C 線儲備糧食將遭遇洗劫踐踏
```

* **直接依賴**：沒有勘測資料，工程仍能施工，但失敗與誤導風險極高。
* **間接影響**：居民信任不直接改變落石重量，卻會決定現場有多少礦工願意拼命拉緊絞盤。

## 五、獨立時間軸模擬進程 (Independent Clock & T-Timeline)

獸潮具有獨立於玩家行動的推演時鐘（T-Clock），時間不會等待玩家完成任務才前進：

| 時間階段 | 世界環境動態表現 | 玩家與 NPC 的行動介入窗口 |
| :--- | :--- | :--- |
| **T−3：異常初顯**<br>(第 19 章晨) | 東林鳥雀驚飛、林冠泛紅霧、北方微風帶硫磺焦味、捕獲獵物驟減。 | A01 採集暴斃黃羊樣本、D01 草廬急救、C01 盤點集市存糧。 |
| **T−2：遷徙確認**<br>(第 20~22 章) | 獸痕密布、食草獸成群南奔；集市爆發米荒衝突，商隊護衛暗中串聯。 | A02 追蹤獸道、A03 踏勘落龍口、E01 組織輪值防衛。 |
| **T−1：大潮臨近**<br>(第 23~26 章) | 先頭花豹與狂狼現蹤；私逃富商車毀人亡；黑石鋪全鎮進入極限備戰。 | B01/B02 架設萬斤石陣、B03 點燃低溫阻獸煙、D02 疏散暗渠。 |
| **T0：主力過境**<br>(第 27~28 章) | 大地劇烈轟鳴，萬獸狂潮奔騰抵達落龍口；阻獸煙起、鳴鏑尖嘯、落石觸發！ | 現場手動觸發拉索、觀測風向切換、防備煙霧倒灌。 |
| **T+1：殘獸清剿**<br>(第 29~30 章) | 獸潮主力怒折落龍澗；一成殘獸衝擊外圍木柵；晨曦破曉，全鎮虛脫清點。 | G01 巷戰補漏、搶救傷患、掩埋獸屍、分配無主雜糧。 |
| **T+2：局勢反噬**<br>(第 31~38 章) | 下泄獸群衝斷金石官道；胡百戶哨騎被困；府城三千重弩大軍扣關對峙。 | F03 拼合證據、H02 多點投書、H03 陣前對質、開啟遠行。 |

> **時間延誤代價**：玩家不做工程，NPC 可能嘗試自發處理（代價更高）；玩家不去救人，居民可能自行搜救並承擔更高傷亡。**玩家缺席不等於世界靜止，玩家介入也不保證必然完美。**

## 七、小說與 MUD 的共用與解耦邊界

* **共用底層世界規則**：獸潮的生態成因（地煞窒息）、地形阻力（落龍深澗寬度與坡度）、物資匱乏量、NPC 利益動機、時間軸演化邏輯。
* **解耦固定劇情路徑**：
  * 小說中五位少年因個人天賦與師承，走出了一條高難度、相對完整的生還之路；
  * MUD 中玩家隊伍可能只完成部分任務，產生豐富且合法的替代歷史：
    * *走向 A*：玩家未能改道成功，但提前疏散大部分居民，黑石鋪雖毀但人口保全。
    * *走向 B*：玩家完美改道，卻忽略糧食調度，大災後引發聚落大飢荒。
    * *走向 C*：玩家成功保全聚落，卻未蒐集走私物證，官軍最終執行強硬封鎖。
    * *走向 D*：玩家完全不參與工程，NPC 自行結伴逃難，黑石鋪淪為大荒廢墟。

## 八、第一版實作範圍（Phase 1 MVP Scope: 8 大核心任務）

為確保系統可驗證且不膨脹，第一階段僅落地以下 **8 個標竿任務**：

1. `A01 暴斃黃羊`（生態勘測・病理起點）
2. `A02 逆行獸跡`（生態勘測・空間方向）
3. `B02 萬斤落石`（地形工程・主力干預）
4. `C01 糧倉盤點`（物資調度・內部生計）
5. `D01 最後一包止痛散`（醫療救援・道德抉擇）
6. `E01 誰來守街口`（居民協作・基層組織）
7. `G01 木柵缺口`（殘獸防衛・邊緣作戰）
8. `F03 證詞互證`（情報查證・政治籌碼）

### 第一階段驗收標準
**不要求玩家必須完成全部 8 個任務；當玩家僅完成其中 2~3 個任務時，世界依然能依照剩餘條件合理自洽地運轉演化。**

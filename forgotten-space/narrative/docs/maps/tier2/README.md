## 地圖資料規範

每個房間至少記錄：`room_id`、顯示名稱、區域、出入口、地形／環境、可進入條件、常駐 NPC、關聯事件、危險與備註。地圖連線要分清楚：一般道路、季節道路、單向落差、需權限通行、劇情暫時封閉。

**驗收狀態**：`draft`。目前未進行程式房間對照、全域 BFS、雙向可逆性、門禁與季節路徑測試。

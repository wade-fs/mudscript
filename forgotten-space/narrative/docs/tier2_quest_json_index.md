# Tier 2 任務 JSON 索引

任務 JSON 初稿位於專案根目錄 `quests/`，與現有引擎的 `main/`、`epic/`、`event/` 分類相同。

- 一般主線：`quests/main/v3_*.json`
- 史詩跨階段：`quests/epic/v3_*.json`
- 世界事件：`quests/event/v3_*.json`
- 世界事件定義：`data/event_defs/tier2_crisis.json`（敘事同步副本：`narrative/events/tier2_crisis.json`）

**注意**：NPC ID 與 room path 取自 Tier 2 名冊／地圖草案，尚未有 LPC 實體；JSON 是格式初稿，不可直接宣稱已可在 MUD 中運作。

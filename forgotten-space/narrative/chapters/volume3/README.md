## 一、本卷大事記（時間跨度：初冬北行至翌年仲春踏入洞天・約五個月）

| 幕次與時序 | 對應章節 | 關鍵事件與轉折 | 付出的代價與留存影響 |
| :--- | :--- | :--- | :--- |
| **第一幕：北上雲津**<br>*(初冬寒原至立冬開山)* | Ch.83 ～ Ch.90 | 隨雪橇女領隊**穆雪**越八百里寒原抵**雲津仙集（萬山商埠）**。沈泥得公所**羅九秤**與雲海票號**顧蘭舟**協助頂住萬寶閣打壓、僱管事**邱禾**立起【泥途商棧】，復自賠違約保住青河藥信並定「朔望貨單繩結暗語」。四位少年各自通過太清天梯、黑山營荒狼試煉、千鍛地火廊拆軸考與百毒試藥谷考校，入列三宗外門。 | 目睹被名山淘汰的退門散修周鐵山、陳青凍餒退返之慘況，深知仙門之外仍有千萬無名凡人替這座大山扛底。 |
| **第二幕：宗門暗影**<br>*(仲冬宗門雜役至歲末)* | Ch.91 ～ Ch.101 | 在繁重雜役與歲貢考校中各自觸及仙門陰暗面：**柳清虛**於藏星秘閣守史老吏**余守拙**暗助下發現六百年星曆**每三百年整體校順一度半**，復於升仙台目睹「坐化」實為高修玉化成晶供能；**燕隼**發現黑山宿將咳黑血吞「急鎮丸」，與總兵**雷烈**探鬼哭冰澗找回燕山斷箭；**林鐵生**修巨靈神機識破**赤煉**強塞血精柱之舉；**顧玄**於廢丹崖與地肺丹火窟查證**鶴壽**煉製【逆道延命血丹】且停藥必亡；**沈泥**截獲私盟索引迎來**莫三**北上護後。然清虛左腕突生早期「道化晶絲」，五人首度藉藥理、高頻微震、陽血、定錨與計時合剝除絲；沈泥外庫隨即遭執法與萬寶閣突查罰損，決意隨隊北探破局。 | **柳清虛**經脈留下麻木失憶與寒蝕舊創；道化剝離僅延緩表症，證實宗門長老集體受困於「不吃毒丹便玉化坐化」的死局。 |
| **第三幕：北荒方舟**<br>*(深冬極寒・出關尋蹤)* | Ch.102 ～ Ch.111 | 五人隨三宗聯合勘探隊踏入極北凍土，抵禦雙頭霜甲地龍伏擊，夜降遭人為炸封之黑冰斷谷尋獲九具走山遺骸與**燕山**殘頁血書（指涉「雷……非……」與暗手）；復於戰神遺塚裂隙邊找回燕山凹損【護心鏡】與拖拽血跡，燕隼放棄追兇而守住同伴撤離。五人穿入冰底奇蹟——**【太古破界方舟北方主陣基】**：方知「血精母脈」竟是太古方舟鎮熱漿液漏蝕而成，五件遺物引發殘像並合璧出完整**【九城古商盟總契銅版】**，揭開三十年前「雲記」因拒交禁毀母脈圖紙而遭滅門之根源。鐵生以死栓搶鎖正被**赤煉**狂鑽爆壓的母液主閥，五人於冰谷殲殺滅口私盟執事，攜鐵證返山並通過苦修派**簡素真人**醫治元青之實證考驗。 | **燕山依然下落不明（生死未卜）**，大黑山線留下更深懸念；失蹤家屬互助會**韓素**收回兄長銅哨，拒絕廉價安撫。 |
| **第四幕：雲頂驚變**<br>*(早春・十年一度三宗會武)* | Ch.112 ～ Ch.120 | 會武天台上，鐵生三錘定破「煞火魔偶」血精脆軸，顧玄以雙試毒針當眾驗出「九轉增元丹」含劇毒，燕隼與清虛接連擊敗服藥狂化與暗藏晶斑之對手；雲津內廳沈泥同步清算萬寶閣挪用準備金、查封黑帳。公審當場攤開四線互鎖鐵證促三大掌門罷免鶴壽、玄冥與赤煉——不料**鶴壽狂吞母液化作噴散毒霧晶簇之活體地獄**，**玄冥逆催封山陣遭反噬左臂碎裂**，**赤煉趁亂遁入地底失蹤**！授業師**陸觀瀾**捨身以紫銅鏡與身軀壓死失控副陣眼三十息，救出兩名衛士卻徹底廢去經絡；地脈大震誘發北荒獸王**【冰獄骨龍】**破關撞塌黑山長城西段！五子依實務協同——沈泥調全埠民車物資、顧玄設隔離藥霧、鐵生控無血精巨靈神機頂柱、清虛定【三元鎮脈陣】、燕隼配合守軍輪替射擊——終遏制毒域並迫退骨龍。 | 長城局部破毀、死傷慘重；鶴壽囚於鐵室垂危、玄冥斷臂推諉、**赤煉潛逃人間未獲**；私爐停業致陶生等底層窯工失業，沈泥立再生回收坊與雲津新約消化餘痛，勝利背後無人歡呼。 |
| **第五幕：排斥與跨界**<br>*(仲春・破極開門)* | Ch.121 ～ Ch.126 | 戰後各自補齊最後一道欠缺（顧玄直面病患拒藥之界線編定本草錄、鐵生拒接活體神識改設可拆連桿、燕隼停步名冊前放下復仇執念、清虛公開星曆反例、沈泥拆分總號獨佔標段為分權共治章程），五人同臻人間道途圓滿門檻；重聚祖庭【封存觀測室】對照五器時，觸動九天「二十八宿假天」與地脈負荷極限，萬里雲津瞬間遭紫黑色「化道滅世劫雲」鎖定！三大掌門坦言歷代至少十七批極境先輩皆曾借祖庭千丈地底單向古陣避入**【桃花源／異界洞天】**，然**無一卷檔案證明門後是否安全或能否生還歸返**。沈泥將泥途總號徹底分權並托付**莫三**守住三十載人間約，接過南方故人書信與蘇凝霜密契，於紫黑神雷劈碎山腹護陣的最後一息，五人攜手撕開光門，墜入頭頂無星無日、三極巨構林立的荒蕪灰原。 | 祖庭主傳送室在身後隨雷劫崩為廢墟，**歸路徹底斷絕**；莫三獨坐泥途總號老茶壺前立三十年之約，而門後並無桃花與仙鶴，唯有令人窒息的鐵青天穹與遠處幽火。 |

## 二、踏入洞天門檻時，五人「已知」與「未知」的認知邊界（Ch.124 ～ 126）

第三卷完結時，五位少年並非無所不知的天命救世主；清楚區分他們手裡的底牌與未解謎團，正是第四卷真正的起點：

* **已經實證掌握的真相（Known）**：
  1. 頭頂二十八宿「天羅」每隔三百年便人為校順一次，當極境生靈與太古遺物同頻超出凡間脆弱承載線時，會招來滅世排斥雷劫。
  2. 北荒冰下並非礦脈，而是一截太古方舟殘骸；所謂地煞血精只是方舟鎮熱漿液長期滲漏之毒液，三宗延命丹鼎與三十年前滅門「雲記」的血案皆源於這條毒鏈。
  3. 歷代至少十七批觸頂前輩走進過地底單向古陣，且「桃花源」對岸確實有一片與凡間天羅隔離的異界天地，卻無一人曾經走回人間半步。
* **依然一片空白的謎團（Unknown）**：
  1. 究竟是誰在萬古之前架設了這座假天羅網？大清洗究竟因何爆發？
  2. 那十七批先賢進去之後究竟成了仙、被困住、還是早已化為某種養料或屍骨？門後的法則壓迫會如何改寫凡間練成的身骨與法訣（甚至連時間流速是否與人間莫三的三十年壽數一致）？
  3. 遠處地平線正北**【太虛神宮】**、西南**【戰祖魔殿】**、正東**【萬物主機城】**究竟何為敵友？北荒僅是一截殘艙，方舟其餘主體又落於何處？

### 五大主角踏入洞天的各自迫切追問
* **柳清虛**（懷揣師長陸觀瀾裂紋紫銅護身鏡）：既見天穹星宿盡數熄滅，是誰造了凡間那座假天牢籠，這方無星天地又是誰的算盤？
* **林鐵生**（握緊阿鐵左手鍛錘與不融黑鐵齒輪）：這片荒原盡頭竟真立著轉動的鋼鐵城郭——方舟其餘的船身在哪裡？世上究竟有沒有不用人命當薪炭也能長久運轉的大器？
* **燕隼**（挽起百斤蛟骨重弓、腕繫韓素厚羊毛護腕）：五年前護心鏡上那道血痕到底是誰引進斷谷的，大伯**燕山**究竟還活著嗎？
* **顧玄**（背負《三元本草祛道錄》初稿與葛半仙草種）：出了凡間天羅之後，凡人身上的道化晶斑究竟會自行消散，還是換成另一場更難醫治的異界死病？元青與陸師長還有沒有解救之法？
* **沈泥**（貼身緊按合璧【九城古商盟總契銅版】、天門引與莫三茶牌）：九城總契為何只寫保人間火種、隻字不提功成歸返？在莫三合眼之前的三十年裡，如何從無門可回的異界重新鑿回這筆人間血帳？

## 三、卷末各方關鍵人物狀態（Ch.126 破界瞬間）

* **跨入桃花源洞天五人**：全數褪去凡俗門檻束縛卻也面對未知異界壓迫與體內舊傷餘患——**沈泥**（自由身行商，持完整版【九城古商盟總契銅版】與【萬物行商・天門引】）、**柳清虛**（太清出身，持【逆星斷碑拓片】與陸觀瀾碎鏡，左手偶發寒麻失憶舊傷）、**林鐵生**（天工閣出身，持【太古不融黑鐵齒輪構件】與阿鐵卡尺鍛錘）、**燕隼**（八荒出身，持【太古戰神獵獸圖騰骨片】與護心鏡，肩胛保留舊傷制約）、**顧玄**（丹鼎宗出身，持【古礦地煞晶核殘片】與本草初稿）。
* **雲津與三宗守望者**：
  * **莫三**（坐鎮萬山泥途總號後廳守老茶壺，執茶牌見證三十年約）；**邱禾**、**顧蘭舟**、**羅九秤**與八商戶代表共同執掌分散共治後的泥途總號。
  * **宋知微**（太清掌院，與紫霄真人聯撐大陣目送五人入陣）、**魯長老・章百鍊**（整頓天工閣地火與工單制度）、**雷烈**（獨臂守黑山長城，不插手商號帳務只護北道）、**簡素真人**（苦修派宿老，照看醫療隔離線）、**白鶴年・孫聞露**（續追晶毒病例與救治工作）。
  * **傷退與遺恨者**：**陸觀瀾**（壓制副陣眼重創經絡與晶化加劇，退居養傷）；**元青**（雖抽去早期晶絲仍需靜養）；**韓素・阿滿**（守望雲津互助會，送出厚羊毛護腕卻絕口不許虛諾）。
* **留待凡間與未解的暗線**：
  * **蘇凝霜**（遙守南方金石商會總堂，已打通虎跳峽便道並派駐商隊北連雲津，正著手向金石內堂殘黨深挖三十年前簽字黑名單並布防追查逃犯行蹤）。
  * **涉案三長老**：**鶴壽**（母液反噬致全身血毒晶化垂危，鐵室看守候審）；**玄冥**（左臂碎裂跌境，交部分帳冊卻咬死不知三十年前血案）；**赤煉**（會武當夜順萬仞天工山廢棄地火暗道潛逃無蹤）。

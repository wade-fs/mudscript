## 一、本卷大事記（時間跨度：初冬入道途至翌年初秋・約兩百日）

| 幕次與時序 | 對應章節 | 關鍵事件與轉折 | 付出的代價與世界留痕 |
| :--- | :--- | :--- | :--- |
| **第一幕：入城通牒**<br>*(初冬・約十餘日)* | Ch.39 ～ Ch.46 | 押解隊改走東線盤木林道四百五十里。峽下驛直面虎跳峽斷道家屬血淚與血書立諾；松崖驛趙德貴中「地陰腐骨散」雖經顧玄救活卻咽喉灼爛難言；盤木林場林鐵生以左手小錘定住崩斜巨木絞盤。抵金石府南關遭稅吏刁難與流民三日大限，總堂靈堂遭錢百川以「附庸賣身契」逼降未果，五人棲身南關狹窄車馬小棧分頭覓得學塾、醫館與車馬行短期保書。 | 初嚐體制「只認銅錢與在冊保牒、不認鄉村功勞」之冷酷，徹底卸下天真；虎跳峽陣亡兵丁與林道受損成五人長久背負之實債。 |
| **第二幕：分途立業**<br>*(深冬至立春・約兩月)* | Ch.47 ～ Ch.57 | 五人依各自本分站穩腳跟：林鐵生（受認出阿鐵錘印之鍛師莫錘考校）領百工匠籍並檢出血精熔渣；顧玄盲辨百藥取得杏林醫籍；燕隼扛四百斤石鎖並於生死擂過三合得八方黑鐵腰牌；柳清虛入宣道司摘星台破白晝盲算星軌得觀象度牒；沈泥於通寶當鋪翻檢舊檔驚見「雲記・雲妮」當票，取得牙人信印。暴雨夜五人於西水門首次三道合力破閘排洪，後在南關盤點出六項核心證據缺口。 | 柳清虛親歷宣道司「絕靈法網」與「五十文一炷香滌塵」之修行銅臭；玄機真人夜巡屋頂警示「宣道司只要長明燈，不要野火」。 |
| **第三幕：六縣連環**<br>*(早春・月餘)* | Ch.58 ～ Ch.67 | 五人各自帶假條與任務枷鎖兵分四路：顧玄在青河破道觀與商會截水囤藥之局；清虛與燕隼於鎮風天風谷採風蝕石英平息欠餉衝突，並查出五年前**大伯燕山持「走山令」探北崖而全隊未歸**及半枚殘牌；鐵生在烈礬地火堡側道鑿風救百餘礦工並取得耐火白泥出貨單，復於重石重造雙齒棘輪絞盤起獲「抽減北崖支護鐵木」指令；沈泥於濁水毒坊截獲軍營毒源單，並在暗渠老帳房柯九算處證實自己確為十五年前覆滅商號「雲記」之女**沈雲妮**。回府匯流時蘇凝霜痛泣父當年涉愧，錢百川突發動跨縣飛錢凍結並軟禁蘇凝霜。 | 非主角介入下六縣早已暗流洶湧：青河藥價飛漲、烈礬減爐熄火、濁水汞毒濫流；沈泥從孤女變為舊血案繼承者，內心對己身定位與莫三隱瞞起疑。 |
| **第四幕：三方會審**<br>*(春末至初夏・近兩月)* | Ch.68 ～ Ch.76 | 飛錢成紙引發擠兌暴漲，顧玄勸開常平倉分級放糧、復於西水門連醫四十八名染毒苦力；鐵生徹夜搶修遭金剛砂卡死之外城水閘並發現錢百川「水淹天字密室」殺招；燕隼擊退北關狼群後自兵器庫與硝火作核對雙聯雷管火印；沈泥偕莫三與驚懼卻守程序的案牘主簿**文承敬**涉水入暗渠，起獲密室正底單加蓋官印火漆，並與玄鐵內門產生感應共鳴。會審公堂上，二十二名黑石礦工當堂亮出傷軀與血指印，趙德貴啞喉爬出指證並留下焦炭畫押，沈泥合對通寶準備金與南關入城稅單戳穿「十二萬兩官銀被劫」彌天謊言，終促**三印合符**鎖拿錢百川下獄、迫開三號庫放銀平市！ | 趙德貴會審後於死牢毒發氣絕，顧玄無力回天；血精崩盤引發烈礬、重石窯工與散人失業，街頭礦工紅著眼咒罵五人；萬老會長裁定蘇凝霜僅得在三老聯署牽制下「暫代」大掌櫃，勝利遠非烏托邦。 |
| **第五幕：鬼市與破障**<br>*(盛夏至初秋・兩月餘)* | Ch.77 ～ Ch.82 | 沈泥深入鬼市以契約分期買下與天門引共鳴的史前青銅契版殘片，自鬼見愁口中追出血精真正買家是**無標記卻帶上界純淨靈石的採辦經生**。莫三返鄉前夜與沈泥冷茶對坐吐露當年雪夜抱孤之實；沈泥保留「沈泥」之名卻接下追查太古舊約之責。其後四少年各自跨過凡胎壁障（鐵生心眼淬體、顧玄通靈藥體、燕隼氣血逆沖學會「等號令」、清虛於靜心閣斬破心魔）；四少年獲頒**名山外門考核令**，沈泥不入仙門而受蘇凝霜與賈朝奉聯署【跨州特等通行信印】。絕靈法網開始排斥高境修為，五件太古遺物於小棧合鳴指向正北雲山，五人於初秋晨光出北關分途北上。 | 虎跳峽條石便道終告修復，黑石鋪寄來故人器物信訊；而無名劍修瞥見逆星拓片頓生殺機、經生重金欲購不融黑鐵遭拒，預告北方名山暗藏更深忌諱。 |

### 金石府留守群像與遠方呼應
* **蘇凝霜**：正式留守金石商會總堂「暫代大掌櫃」（受萬老會長與三老聯署牽制），親歷父親當年遺恨與「雲記」舊愧後更見沉毅，成為五人最穩固的南方後勤支點。
* **文承敬**：府衙案牘主簿，五十餘歲謹守程序卻因十五年前掩案愧疚而挺身入險水蓋下官印；會審後繼續坐鎮案卷庫與法度細節。
* **陳鎮山・雷震・霸山**：鎮武軍鎮諸將經歷斷道之痛與雙聯火印案，與五人建立「重實據、守軍律」之硬派互信；其中**雷震**當年錯漏之線索直連第三卷北境軍屯舊部。
* **莫三與魯大山**：於初秋隨商隊返抵黑石鋪，將黑石後巷與重石條石接通成實質山貨轉運點，遙遙守望南方後路。

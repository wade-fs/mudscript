## 一、本卷大事記（時間跨度：黑石鋪八晝夜）

| 時序 | 對應章節 | 關鍵事件與轉折 | 付出的代價與留存影響 |
| :--- | :--- | :--- | :--- |
| **第一日・破曉至深夜** | Ch.1 ～ Ch.12 | 同一清晨，五位底層少年於黑石鋪各自觸碰太古遺物；晨集因生計初遇。南谷伏擊中燕隼激發圖騰血氣反殺胡三；暗巷內逆星拓片與道門銅圖合契；暴雨夜五人自城防弩衛圍剿下救出金石商會大小姐**蘇凝霜**，並引出五位隱世殘老導師暗中護短。 | 燕隼、顧玄等首度見血；五位長輩暗中動用舊傷殘器震懾城防司，伏下更深忌憚；夜半地煞猛然逆衝，北崖古礦塌方。 |
| **第二日・深井救援** | Ch.13 ～ Ch.18 | 趙德貴企圖封山滅口，蘇凝霜憑紫金雙龍印血書簽發救援委託。五子入井開鑿排沙暗渠救出**二十三名礦工**，起出軍用雷管引信與精煉坩堝碎塊。深夜火塘前五人對未來道途激烈交鋒，接獲城防司調兵三千駐紮虎跳營欲封山屠鎮的急報。 | **林鐵生右腕骨裂**；**老李頭**為護徒**柱子**吸入毒煙瀕危；**孫大牛**右小腿重傷；**魯大山**肩傷。五人明確道途分歧卻立下生死互保約。 |
| **第三日・煞潮勘察與導流** | Ch.19 ～ Ch.27 | **老李頭**在草廬主動推讓救命野山參留給柱子與孫大牛後安詳辭世；顧玄剖檢暴斃黃羊證實地煞煙塵驅獸南遷。五人勘測落龍口，改以斜石碎石障與苦草低溫煙霧借風偏折獸群，雖面對「轉嫁下游官道」之沉重愧疚仍咬牙執槓。 | 王、周富戶私逃車隊在南谷遇伏覆滅，倒扣出【金石內造・丙字柒號】坩堝；二號支點石柱崩塌致王老四重傷，全鎮被迫棄僥倖協力守夜。 |
| **第四日・偏折、巷戰與斷道** | Ch.28 ～ Ch.31 | 辰末獸潮抵近落龍口，八成順深澗南湧，餘波撞破黑石鋪外柵。眾人依品字車陣、鐵索與屋頂分流退敵。傍晚斥候確認獸潮正午沖毀下游虎跳峽木棧道，斷絕胡百戶退路卻也造成官兵死傷。 | **木匠老陳**以榆木檁捨身頂門擋住野豬王，壯烈殉難；外街豆腐坊等民房損毀，劫後仍見底層搶糧分肉之真實人性。 |
| **第五至八日・關前破局與啟程** | Ch.32 ～ Ch.38 | 沈泥與莫三潛行排沙暗渠，多點投書遞交雷管批號、暗賬抄本與礦工家書至先鋒參將**陳鎮山**、監軍與督糧官手中；校場公開勘驗解除胡百戶職權並收押趙德貴。眾人整備重建南山青石場，五子各自圓滿凡胎極境，辭別師長護送證物沿大荒官道赴金石府城。 | 胡、趙押解入城候審，然真正買家直指府城商會高層；虎跳峽便道搶通，五子與蘇凝霜初次背負下游傷亡之債踏出黑石群山。 |

## 二、卷末主要人物狀態與動向（Ch.38 離鄉時刻）

### 五大主角（凡胎圓滿・初離邊陲）
| 人物 | 本卷身分與立足技藝 | 隨身關鍵器物／太古遺物 | 身體狀態與心理執念 |
| :--- | :--- | :--- | :--- |
| **顧玄** | 瘋郎中徒弟；通藥理辨毒與寒針截脈 | 【逆星斷碑拓片】（已傳予清虛互驗）與【古礦地煞晶核殘片】、葛半仙贈毒經禁忌半冊 | 經歷老李頭離世後褪去天真；深知「藥石有窮盡」，誓言向金石府城查清血精毒源。 |
| **林鐵生** | 阿鐵門下學徒；由蠻力轉悟結構應力 | 【太古不融黑鐵齒輪構件】、阿鐵親贈「左手小鍛錘」 | **右腕骨裂尚打夾板以左手應事**；欲尋真正配得上不融黑鐵與百工匠心的鍛爐規矩。 |
| **燕隼** | 獵戶之子；荒野追蹤、群獸預判與重弓箭手 | 【太古戰神獵獸圖騰骨片】（兼身具圖騰血印）、趙伯所傳百斤牛筋蛟骨弓與白鷹破甲箭 | 大伯**燕山**五年前失蹤僅留舊柴刀；牢記「山外之人吃飽亦吃人」，警惕北上線索。 |
| **柳清虛** | 破落老松觀道童；觀星測風、地形推演 | 溪畔所拓【逆星斷碑拓片】＋道門殘圖合卷 | 曾因窺見蒼穹天羅牢籠吐血，如今踏地實證：「縱在籠中，亦要丈量每一寸鐵欄。」 |
| **沈泥** | 後巷流浪孤兒；市井耳目與風險清算（實為女身，對外仍常偽作少男） | 後巷黑泥起出之黑鐵包皮青金古令【萬物行商・天門引】、莫三硬塞的半塊青稞麥餅 | 既記莫三三十年遮掩庇護之情，又隱約嗅見天門引與金石商會總堂密室間的宿命牽連。 |

### 核心同行者、留守師長與逝者
* **同行者**：**蘇凝霜**（金石商會大掌櫃蘇遠山之女，身懷紫金雙龍印與父親暗賬，赴府城追查商會謀逆與血精大買家）；**陳鎮山**（鎮武軍鎮左參將，領輕騎押解胡百戶、趙德貴回府候審）。
* **留守黑石鋪師長**：**老鐵匠阿鐵**（右前臂道化冷晶隱患未除）、**瘋郎中葛半仙**（草廬守醫）、**趙老獵**（老寒腿鎮守哨亭）、**枯木老道**（盲眼守殘觀，僅囑「別信這片天」）、**老丐莫三**（守後巷漏風柴房，為沈泥留半邊鋪草）、**魯大山**（左肩傷癒後領傷殘礦工改採南山青石）。
* **本卷逝者**：老礦工**老李頭**（井下以身護徒、讓藥辭世）、木匠**老陳**（以榆木檁頂門殉難）；另有**孫婆婆**、柱子、孫大牛與**小泥鰍**等鄉親留守重整家園。

## 三、邁入第二卷前的核心懸念

1. **天字一號密室與「血精」買家**：趙德貴只認了接單除渣，真正批發三萬斤血精結晶的府城勢力是誰？與金石商會副會長錢百川有何關聯？
2. **「天門引」與沈泥身世**：這枚青金古令為何能呼應商會密室？沈泥從何而來？莫三隱忍三十年沒說出口的過往究竟是什麼？
3. **凡俗規矩的考驗**：脫離彼此守望的黑石鋪後，五個沒有戶籍保書、右腕帶傷的邊陲少年，如何在律法森嚴的金石自治城邦活過頭三天？

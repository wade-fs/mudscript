# 第三卷事件紀錄簿（Tier 2 Event Ledger）

> 版本：0.1（第一階段世界建設）  
> 事件 ID：`EV3xx`  
> 原則：事件是世界狀態的變化，不等同任務；任務是角色可採取的行動鏈，第二階段再建立 JSON。事件證據嚴守第二卷五欄物證鐵律。

## 0. 事件資料欄位

每筆事件應記錄：`event_id`、時間／季節、地點、參與者、觸發條件、可觀察現象、實際原因（若尚未證實則標 open）、結果、世界狀態影響、證據及證明力限制、關聯章節、關聯任務。

證據等級沿用：`lead_only` → `corroborative` → `conclusive`。不得因主角推理合理就自動升級。

## 2. 事件詳目

### EV301：北境雪原行旅與淘汰者相遇

- **時間**：第二卷第 82 章初秋離城後；實際抵達季節須由時間軸校準。
- **地點**：金石北關至雲津的北境雪原官道。
- **參與者**：五位主角、莫三、商隊、被名山淘汰的修士與隨行家屬。
- **可觀察現象**：道路越往北越寒，靈氣環境變化；被遣返者經脈受損、債務未清，部分人不願談入門經歷。
- **事件價值**：讓讀者看到名山制度在入門考核以外的社會成本；避免把「考不上」只寫成背景數字。
- **證據限制**：淘汰者的控訴是個人證言，不足以證明宗門普遍故意傷害弟子。

### EV302：雲津商埠入市與保證金爭議

- **地點**：雲津萬山廣場、西街貨棧區、公所。
- **參與者**：沈泥、何萬金、羅九秤、邱禾（提案人物）、商埠公所職員。
- **觸發**：沈泥持金石商會與通寶跨州特等通行信印申請落腳經營。
- **衝突**：信印證明其行商資格，不代表免除當地保證金、倉儲責任或信用審查。
- **結果方向**：沈泥以可驗證的六縣供應契約談判取得小型貨棧，不應一步成為商埠巨賈。
- **待定**：保證金數額、租期與公所席位規則。

### EV303：三山外門考核分流

- **地點**：太清登天雲梯、八荒萬鈞問心谷、千機百巧門考場。
- **參與者**：柳清虛、燕隼、林鐵生、顧玄及各宗門考核者。
- **事件核心**：四人分別接受不同考核，考核不只是力量測試，也檢驗方法、判斷與承擔後果的能力。
- **沈泥線**：不入宗門，留在雲津建立商棧；其故事不可被寫成四人修行線的附屬後勤。
- **待定**：考核是否同日舉行；需配合「三年一度」制度與卷二時間軸。

### EV304：星曆原件與修訂本差異

- **地點**：太清周天星律院、藏星秘閣。
- **參與者**：柳清虛、宋知微、陸觀瀾、余守拙、沈照塵。
- **可觀察現象**：部分舊星圖的觀測值與後世重抄版本存在差異，修訂理由不完整。
- **推論邊界**：這只能證明檔案有修訂及來源缺口，不能直接證明所有星軌都被人為操控。
- **後續**：需要跨年代原始觀測、獨立儀器或其他地域星圖交叉驗證。

### EV305：黑山營傷兵氣血衰竭

- **地點**：八荒煞血營、傷兵養息院。
- **參與者**：燕隼、雷烈、岳停山、杜青禾、傷兵。
- **可觀察現象**：部分老兵表面仍能作戰，休息後出現黑血、震顫、脾胃衰弱及情緒失控。
- **證據限制**：個別症狀不能直接歸因於血精；須排除舊傷、寒毒、過度訓練與其他藥物因素。
- **戲劇功能**：燕隼看到武山守住邊境的真實代價，也理解改革可能削弱短期防禦。

### EV306：萬機地窟母機異常脈衝

- **地點**：天工閣萬機地窟。
- **參與者**：林鐵生、魯長、季衡、聞九。
- **可觀察現象**：沉寂機件出現規律振動，部分構件與林鐵生持有的太古不融黑鐵具有相似材質特徵。
- **證據限制**：材質同源不等於機件可互換；脈衝來源未明前不可稱為母機已甦醒。

### EV307：百草谷藥田與地肺水質異常

- **地點**：丹鼎宗百草谷、地肺水渠。
- **參與者**：顧玄、葉青枝、孫聞露、藥農。
- **可觀察現象**：部分藥田葉片出現相似斑紋，藥材藥性波動；水渠沉積物有異常礦物成分。
- **證據限制**：需對照上游水樣、土壤、種苗與不同批次藥材，不能僅憑外觀判定血精污染。

### EV308：廢丹批次流向與延命丹病例

- **地點**：地肺丹火窟、醫理院、廢丹崖。
- **參與者**：顧玄、鶴壽、白鶴年、孫聞露、陶生。
- **可觀察現象**：部分延命丹的批次、藥渣與病案紀錄對不上；有廢丹被重新封裝或轉運的疑點。
- **證據鏈**：批號、爐次、封泥、庫房出入簿、病患同意紀錄、藥效追蹤。
- **證據限制**：藥效異常不等於已證明原料來自黑石鋪血精；需與商埠交割帳及北荒母脈資料互證。

### EV309：泥途商棧首次履約危機

- **地點**：雲津西街貨棧區、三宗交易街。
- **參與者**：沈泥、邱禾、何萬金、顧蘭舟、三宗採辦。
- **衝突方向**：一批冬季藥材因道路封雪延遲，沈泥必須選擇違約賠償、改道高價運送或與客戶協商分批交付。
- **人物核心**：她的信用不能靠主角光環維持；履約會造成實際資金損失或人力風險。

### EV310–EV318：北荒勘探與走山隊真相

- **EV310**：三宗聯合勘探隊出發。任務公開理由為地脈異動與長城陣基勘察；各方私下目的不完全一致。
- **EV311**：永凍血原遭荒獸伏擊。戰鬥必須呈現隊伍協作、傷亡、補給消耗與撤退選項，不只展示主角技能。
- **EV312**：黑冰斷谷發現走山隊遺址。燕隼取得燕山箭記、血書與隊員遺物；每件物證獨立編號與封存。
- **EV313**：發現護心鏡與裂隙痕跡。只能證明燕山曾抵達裂隙附近，不能直接證明他已生還或成功進入洞天。
- **EV314**：方舟北方主陣基初次勘驗。林鐵生確認部分構件與太古不融黑鐵同源；顧玄辨識出異常物質樣本；柳清虛記錄陣基周圍的星象偏差。
- **EV315**：五件遺物共鳴，呈現有限光影資料。畫面可能殘缺、缺少上下文或受損；不可一次解釋整個太古文明史。
- **EV316**：沈泥以天門引及青銅契版接觸北方契約資料。資料揭示九城商盟曾承擔後勤調度職責，但其完整法律效力、沈家責任與三十年前清洗的全貌仍需交叉證明。
- **EV317**：鑽山傀儡盜掘造成母脈壓力異常。必須記錄設備批次、操作者、命令來源與現場樣本。
- **EV318**：冰谷伏擊。五人自衛反擊並保存證據；是否由某位長老直接下令，須有命令鏈或多方證詞，不能只憑死士口供定案。

### EV319–EV325：雲頂會武、危機與改革

- **EV319**：五人返回雲津後封存物證，建立保管鏈，聯絡三宗內部不同立場者。
- **EV320**：三宗論道會武是公開盛會，包含技藝、武備、丹器與商埠交割展示；不應只作為主角比武舞台。
- **EV321**：各方提出帳冊、病案、軍需與器材記錄，證據互相矛盾之處要保留，讓讀者看到調查成本。
- **EV322**：長老道化急變。病患危機先於政治揭露；救治與隔離有時間壓力，不能只當成反派變身。
- **EV323**：獸潮壓迫防線，迫使各宗門暫時合作。傷亡、城寨損毀與戰後補給必須入帳。
- **EV324**：三元互濟只能完成有限病例或局部機制驗證，不等於徹底治癒所有反噬。
- **EV325**：改革提案遭遇利益反彈。血精禁用、替代療法、工匠生計、前線戰力與宗門權力必須同時考慮。

### EV326–EV327：卷末跨界

- **EV326**：五人二階圓滿及假天排斥徵兆。修為提升不等於理解全部法則；排斥機制須依 `world_setting.md` §3.9、§3.13 補足成本與條件。
- **EV327**：北方古陣開啟，通往 Tier 3 的入口呈現單向或高風險特性。開啟前須確認撤退、補給、同行者知情及回返可能性；不得把進入洞天當成無成本傳送。

## 3. 第二卷正典銜接檢查

- 燕山：燕隼的大伯，第二卷已明確如此記載。
- 顧玄遺物：古礦地煞晶核殘片；不得與柳清虛的道化晶石殘片混用。
- 柳清虛遺物：逆星斷碑拓片及道化晶石殘片是不同物件。
- 林鐵生遺物：太古不融黑鐵／黑鐵齒輪系統，具體實體與零件關係須按第二卷清單統一。
- 燕隼遺物：太古戰神獵獸圖騰骨片及燕山走山令殘牌，兩者功能不同。
- 沈泥遺物：天門引、青銅契版、雲記名冊等屬不同證據／信物，不得合併成單一「商盟神器」。
